How to get an app-password + enable IMAP

Gmail: Turn on 2-Step Verification, then create an App Password at myaccount.google.com/apppasswords. IMAP host imap.gmail.com, port 993. Enable IMAP in Gmail → Settings → Forwarding and POP/IMAP.

Outlook / Microsoft 365: Enable 2-Step Verification, create an app password in Security settings. IMAP host outlook.office365.com, port 993.

Yahoo: Account Security → Generate app password. IMAP host imap.mail.yahoo.com, port 993.

Credentials and app-passwords are stored only on this computer.
